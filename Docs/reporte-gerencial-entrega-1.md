## 2. Estado general del proyecto

El proyecto SGPI actualmente sigue en proceso de desarrollo. Desde sus inicios se han refinado y organizado las historias de usuario correspondientes, se ha actualizado la documentación oficial del proyecto hasta las últimas modificaciones de este y, por último, se ha establecido la organización del equipo de trabajo.

Se realizó un Lean Canvas, en el cual se encuentra la propuesta de este proyecto, se realizaron requisitos funcionales y no funcionales. Además, se planteó un calendario de actividades, en el cual se encuentran las 20 historias de usuario (HU), los Sprints, los Issues, los Milestones y demás. Todo se encuentra bien estructurado en el tablero Kanban correspondiente al proyecto SGPI.

Además de esto contamos con documentos oficiales y gerenciales, como lo pueden ser las Actas de Reuniones, el WBS y el Organigrama y el Informe de Resultados.

Actualmente seguimos trabajando en las actividades que aún se encuentran pendientes y en la revisión de entregables requeridos por el proyecto SGPI.

## 6. Problemas encontrados y tratamiento

| Problema | Impacto | Tratamiento |
|---|---|---|
| Historias de usuario que requerían mayor organización | Dificultad para integrarlas correctamente con la planificación del proyecto | Refinamiento y organización de las 20 historias de usuario |
| Gran cantidad de elementos de planificación | Mayor dificultad para mantener coordinados Sprints, Issues y Milestones | Organización conjunta de los elementos dentro de GitHub Projects |
| Necesidad de visualizar el avance del proyecto | Dificultad para identificar rápidamente el estado de las actividades | Implementación y organización del tablero Kanban |
| Documentación distribuida entre diferentes entregables | Dificultad para mantener una estructura clara y coherente | Actualización y organización de la Wiki, estructura del repositorio y documentos oficiales |
| Necesidad de definir claramente las responsabilidades del equipo | Posible confusión sobre las funciones de cada integrante | Elaboración del WBS y Organigrama |
| Necesidad de mantener evidencia del seguimiento del proyecto | Dificultad para demostrar las reuniones y avances realizados | Elaboración de Actas de Reuniones y Reporte Gerencial |
| Necesidad de consolidar la propuesta y los requerimientos del sistema | Dificultad para mantener una visión clara del alcance y funcionamiento esperado | Elaboración del Lean Canvas y definición de requisitos funcionales y no funcionales |
